# 音符切分模块 四层设计（domain/segment）

> 本质锚定：在"翻译器"的时空约束下，本模块的本质是**把连续的 F0 轨迹离散化为人可读的"音符"单元**——空间离散化是唱名映射的前提。

## 数据规范

- 输入：`PitchTrack`。输出：`Note{startSec, endSec, midi(中位连续值), cents(相对最近半音偏差), conf}`。
- 切分规则（常量集中于 core/constants）：音高步进阈 **0.8 半音**（抗颤音，颤音典型 ±0.5）；静音容忍 **≤2 帧**（~48ms）；最短音符 **80ms 且 ≥4 帧**（滤气声/爆破毛刺）。

## 数据存储

无持久化；音符数组即产物，归 application 会话所有。

## 数据流转（状态机式单遍扫描）

```
对每帧: voiced?
 ├─ 否 → unvoicedRun++；run > 2 → 结束当前音符
 └─ 是 → 与"当前音符参考音高"(末5帧中位)差 ≥ 0.8?
      ├─ 是 → 结束当前音符，开启新音符
      └─ 否 → 加入当前音符
结尾 flush；不足最短时长的段落丢弃。
```

音符 midi 取段内中位（抗局部毛刺），cents = (midi − round(midi))×100（供 UI 提示"低了32音分"）。

## 数据接口

```ts
export function segmentNotes(track: PitchTrack, opts?: Partial<SegmentOptions>): Note[]
```

## 生命周期钩子

纯函数无状态（同 04 声明）。

## 验证

合成旋律（400ms 音符 + 60ms 间隙）切分数量与真值一致；八度滑音（连续变化）不被切碎（负例）。
