# 找调儿 FindMyKey 模块设计（模块划分 + 接口契约）

## 1. 模块划分

```
找调儿 FindMyKey
├── core/        数据规范：types / constants / errors / synth（离线合成器）
├── domain/      流转-规则（纯函数域）
│   ├── yin            YIN 音高检测原语               ✅ 四层设计 04
│   ├── pitch-track    帧级 F0 轨迹（滤波+八度纠错）    ✅ 四层设计 04
│   ├── segment        音符切分                        ✅ 四层设计 05
│   ├── tonality       调性推断                        ✅ 四层设计 06
│   ├── solfege        首调唱名映射                    ✅ 四层设计 06
│   └── voice-range    音域测量与推荐调                ✅ 四层设计 07
├── application/     会话状态机 + 用例编排（含 LivePitcher）
│   └── describe         v1.1 大白话叙述（describeMelody/describeRange）  ✅ 四层设计 08
├── infrastructure/  capture-worklet.js + piano-audio（PianoPlayer）✅ 四层设计 08
├── runtime/engine.ts    音频引擎生命周期（时空管家）
└── interfaces/      ui.ts + piano.ts（PianoBoard）+ style.css      ✅ 四层设计 08
```

## 2. 核心类型契约（core/types.ts，全部模块的唯一 DTO 来源）

```ts
export interface PitchFrame { t: number; midi: number; prob: number; rms: number; voiced: boolean }
export interface PitchTrack { frames: PitchFrame[]; hopSec: number }
export interface Note { startSec: number; endSec: number; midi: number; cents: number; conf: number }
export interface KeyCandidate { tonicPc: number; mode: 'major' | 'minor'; score: number }
export interface SolfegeNote {
  degree: 1|2|3|4|5|6|7; accidental: -1|0|1; octaveShift: -2|-1|0|1|2
  midi: number; startSec: number; endSec: number; cents: number; symbol: string
}
export interface VoiceRange { lowMidi: number; highMidi: number; spanSemitones: number; centerMidi: number; recommendedTonics: number[] }
export interface AnalysisResult { track: PitchTrack; notes: Note[]; keys: KeyCandidate[]; solfege: SolfegeNote[] }
```

## 3. 接口契约（类-属性-方法-路由，均回溯本质"翻译器"）

### domain（纯函数，同输入同输出）

| 方法 | 签名 | 本质锚定 |
|------|------|---------|
| yinDetect | `(buf: Float32Array, sampleRate: number) => { hz: number; probability: number }` | 形状提取的最小原语 |
| trackPitch | `(buf, fs?) => PitchTrack` | 把音频流翻译为 F0 时间序列 |
| segmentNotes | `(track) => Note[]` | 把连续轨迹离散化为音符单元 |
| inferKey | `(notes) => KeyCandidate[]`（top3 降序） | 推断"你把哪个音当 do" |
| toSolfege | `(notes, key) => SolfegeNote[]` | 形状 → 首调唱名（路由：任意 key 可重映射） |
| measureRange | `(track) => VoiceRange`（异常：RANGE_INSUFFICIENT / RANGE_TOO_NARROW） | 嗓音舒适区 → 主音坐标 |
| suggestTranspose | `(songLow, songHigh, voiceLow, voiceHigh) => number` | 任意歌翻译进你的调（预留） |

### application/session（编排）

| 方法 | 签名 | 说明 |
|------|------|------|
| analyzeRecording | `(buf: Float32Array, fs?) => AnalysisResult` | 翻译用例（顺序管道；空序列抛 NO_TONE） |
| analyzeRange | `(buf, fs?) => VoiceRange` | 校准用例 |
| rekey | `(result, tonicPc, mode) => SolfegeNote[]` | 主音切换重映射（不改切分，I 不变量） |
| LivePitcher | `class { push(chunk, cb: (midi: number \| null) => void) }` | 校准实时音高句柄（滑动窗） |

### runtime/engine（生命周期）

| 方法 | 钩子语义 |
|------|---------|
| `init()` | 开辟空间：AudioContext(16k) + worklet 模块加载 |
| `start(hooks: { onLiveMidi? })` | 启动时间流：mic → worklet → 消息泵；帧经 transferable 零拷贝 |
| `stop(): Promise<Float32Array>` | 暂停：断链/停轨/拼接 16k mono 缓冲（含重采样兜底） |
| `destroy(): Promise<void>` | 逆序回收：node → tracks → ctx.close → 置空 |

### interfaces/ui（路由=情境适配）

| 入口 | 情境适配 |
|------|---------|
| 「测我的调」 | 校准情境：实时音高画布 → 8s 自动停 → 音域图 + 推荐主音 |
| 「哼唱翻译」 | 翻译情境：≤15s 录音 → 唱名时间线 + 音分提示 + 调性 top3 选择器 |
| 「示例音频」 | 无麦克风情境：内置合成《小星星》走同一管线（验证入口） |

## 4. 全局状态与规则

- **单一状态源**：业务状态（当前结果、所选主音、录音态）仅存于 `application` 与 UI 局部变量；domain 零状态。
- **跨模块访问**：一律经 §2/§3 契约，禁止直接操作他层内部字段。
- **错误路由**：domain 抛 `DomainError(code)` → application 不捕获（保持纯）→ interfaces 捕获并转用户文案（NO_TONE→"没听清，请再哼一次"；RANGE_TOO_NARROW→"请从最低哼到最高"）。
