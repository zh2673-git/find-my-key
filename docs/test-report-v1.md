## 3. 时空闭环检查

- ✅ 所有 init 都有对应 destroy：`AudioEngine.init/start/stop/destroy` 显式四钩子，destroy 按依赖逆序（node→tracks→ctx.close→置空）；UI `beforeunload` 触发。
- ✅ 无时间死锁：录音有硬上限（校准 8s / 翻译 15s 自动停）；worklet 消息泵为单向事件流。
- ✅ 无规则穿透：录音不落盘不上传；UI 只读订阅 application 结果；domain 零 IO。
- ⚠️ 遗留（记录为反模式）：**测试真值源本身可能有 bug**——滑音 2 倍频事件最初误判为 YIN 缺陷，实际是合成器相位错误。"先验证测量工具，再怀疑被测对象" 应入库。
