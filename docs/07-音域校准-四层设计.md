# 音域校准模块 四层设计（domain/voice-range）

> 本质锚定：在"翻译器"的时空约束下，本模块的本质是**把"嗓音这件乐器"的舒适区翻译成主音坐标**——找 key 即给声带定把位。

## 数据规范

- 输出 `VoiceRange{lowMidi, highMidi, spanSemitones, centerMidi, recommendedTonics: number[]}`。
- 异常规则：有声帧 <20 → `RANGE_INSUFFICIENT`；跨度 <10 半音 → `RANGE_TOO_NARROW`（引导"请从最低哼到最高"）。
- 推荐主音带：存在 m ≡ t (mod 12) 使 `m−5 ≥ 舒适低限 且 m+9 ≤ 舒适高限`（旋律典型跨度：do 上方最多 la(+9)，下方最多 sol(−5)）。

## 数据存储

无持久化；校准结果属 application 会话，UI 只读（P2 可选 localStorage 记忆，当前不做）。

## 数据流转（滑音 → 百分位 → 主音带）

1. 引导用户 8 秒从最低滑到最高（UI 实时音高画布反馈，LivePitcher 逐窗 YIN）。
2. 轨迹有声帧 midi 升序 → **p3 / p97 百分位**裁剪（去破音、假声切换毛刺——极限音高对选调无用，反常识根因见 02 §4）。
3. 自然中心 centerMidi = low + 0.35×span（旋律重心偏音域中上部）。
4. 扫 12 个主音候选落入主音带 → `recommendedTonics`。

预留：`suggestTranspose(songLow, songHigh, voiceLow, voiceHigh)` —— 最小 |shift| 使 `[songLow+shift+1, songHigh+shift−1] ⊆ [voiceLow, voiceHigh]`（任意歌翻译进你的调）。

## 数据接口

```ts
export function measureRange(track: PitchTrack): VoiceRange
export function suggestTranspose(songLow: number, songHigh: number, voiceLow: number, voiceHigh: number): number
```

## 生命周期钩子

纯函数无状态；实时反馈所依赖的 LivePitcher（application）为有状态句柄，随录音 stop 一并丢弃。

## 验证

合成指数滑音 110Hz→440Hz（3s）→ 检测低/高误差 ≤2 半音；窄滑音（<10 半音）必须抛 RANGE_TOO_NARROW；主音带含 G3–C4 档位且不含超出舒适区的极端音。
