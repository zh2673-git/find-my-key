# 音高跟踪模块 四层设计（domain/yin + domain/pitch-track）

> 本质锚定：在"翻译器"的时空约束下，本模块的本质是**从音频帧流中提取"旋律形状"的原料——稳定的 F0 时间序列**。

## 数据规范（类型与常量规则）

- 输入：16kHz 单声道 Float32 帧窗（FRAME_SIZE=1024，HOP=256）。
- 输出：`PitchFrame{t, midi, prob, rms, voiced}` 序列（midi 为连续值，不预先量化）。
- 值域规则：hz ∈ [30,1200] 否则判无声；voiced = prob≥0.5 且 rms≥max(0.004, 全局p95×0.06)。

## 数据存储（空间落地）

无持久化。帧窗 `Float32Array` 为栈上临时空间（YIN 的 diff/cmnd 各 512 长临时数组，每帧分配后由 GC 回收——纯函数域不持有跨帧引用）。

## 数据流转（时间编排）

1. **滑窗**：每 256 样本取 1024 窗。
2. **YIN**（纯函数 `yinDetect`）：
   - 差分函数 `d(τ) = Σ (x[j]−x[j+τ])²`，τ ∈ [0,512)；
   - 累积均值归一 `d'(τ)`（压制高频误检）；
   - 绝对阈值 0.12 找首个谷 → 抛物线插值亚样本精化 → `f0 = fs/τ`；`prob = 1−d'(τ谷)`。
3. **RMS 自适应静音门**（全局百分位，抗环境噪声）。
4. **中值滤波**（窗 5，仅对有声帧）去颤音抖动。
5. **八度纠错**：帧 midi 与 ±4 帧局部中位差 >9 半音 → 判为八度跳变，回贴局部中位。

## 数据接口（对外契约）

```ts
export function yinDetect(buf: Float32Array, sampleRate: number, threshold?: number): { hz: number; probability: number }
export function trackPitch(buf: Float32Array, fs?: number): PitchTrack
```

## 生命周期钩子

纯函数无状态：`init/destroy = 无操作`（以"零共享可变状态"替代钩子——I 不变量"同输入同输出"由构造保证）。

## 验证

- 合成音阶 F0 误差 <0.2 半音（Q）；滑音全程跟踪无丢帧（Q）；八度跳变注入后纠错（I）。
